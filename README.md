## Local Setup & Installation

Follow these steps to deploy and explore the projects locally:

### 🔹 For Static HTML/CSS Labs (Lab 01 - 06):
1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd VLU-UI-UX
   ```
2. **Run using Live Server (VS Code):**
   - Open the specific lab folder (e.g., `lab06`) in Visual Studio Code.
   - Right-click on `index.html` and select **"Open with Live Server"**.

### 🔹 For the Next.js Portfolio Environment:
1. **Navigate to the portfolio directory:**
   ```bash
   cd portfolio
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
   > The application will be running at `http://localhost:3000`.

## Design Philosophy

The UI/UX implementations in this repository strive for a **"Cinematic Deep Tech"** and **"Minimalist Japanese"** aesthetic. By prioritizing clean code architecture, absolute usability, and accessible design patterns, each interface aims to deliver an immersive, premium user experience. Every pixel is intentional, avoiding unnecessary visual clutter.
